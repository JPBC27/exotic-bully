# Web de cachorros exotic bully

Sitio estático (HTML, CSS y JS puro) publicado con GitHub Pages.

- `index.html` — estructura de la página
- `css/estilos.css` — colores y diseño (paleta negro y oro en `:root`)
- `js/datos.js` — lo que editas en el día a día: marca, WhatsApp, redes, cachorros, padres y videos
- `js/app.js` — filtros, fichas, WhatsApp y videos
- `js/perro3d.js` — perro 3D de la portada (colores del pelaje al inicio)
- `img/` y `videos/` — fotos y videos
